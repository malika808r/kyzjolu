# Обновление архитектуры KyzJolu (MVP)

Этот план описывает шаги по переходу приложения к чистой, минималистичной структуре из 4 экранов, оставляя только премиальный функционал и убирая визуальный шум.

## User Review Required

> [!IMPORTANT]
> Подтвердите использование таблицы `posts` для создания "Глобальных комнат". 
> Так как оригинальная таблица чатов (`messages`) жестко привязывает сообщения к реальным пользователям (один-на-один), для общих чатов по интересам оптимальнее и безопаснее переиспользовать уже существующую в базе сущность `posts`. Этим мы достигнем общей видимости для всех без создания сложных таблиц с ролями. Если вы согласны, я всё настрою.

## Verification Plan

### Automated Tests
- Запуск `npm run dev` для проверки работоспособности навигации и отсутствия битых ссылок.
- Тестирование перехода между 4 табами вёрстки.

### Manual Verification
- Пользователь сможет войти в приложение, сразу попасть на Карту.
- Пользователь сможет перейти в Комьюнити, выбрать чат "Спорт и Здоровье" и отправить туда сообщение, которое увидят другие.
- Пользователь сможет увидеть чистое расписание в Kyz Hub и сохранить его в профиль.
